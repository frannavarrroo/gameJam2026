<h1>MaskShot</h1>
This game was made in 48 hours for the Global Game Jam event in Córdoba, Argentina. The task was to make a game that had to do with the word <b>mask</b>. We built this game without any prior game development knowledge.
You can find the game's official page <a href="https://globalgamejam.org/games/2026/maskshot-2">here</a>.
